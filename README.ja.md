# Menu Hub for macOS

[最新リリースをダウンロード](https://github.com/Talljack/menu-hub/releases/latest) · macOS 14 以降 · Apple Silicon / Intel 対応

Menu Hub は、macOS ネイティブのメニューバー管理アプリです。四つ葉のアイコンから、実行中のアプリのメニューバー項目を検索、識別、整理、実行できます。

  <img src="docs/images/menu-hub-panel.png" alt="検索可能なメニューバーアプリをコンパクトな macOS パネルに表示する Menu Hub" width="520">

Swift 6、SwiftUI、AppKit で構築し、公開 macOS API のみを使用しています。Electron、コードインジェクション、画面収録権限、分析 SDK、クラウドサービス、アカウントは使用しません。

## インストール

1. [GitHub の最新リリース](https://github.com/Talljack/menu-hub/releases/latest)を開きます。
2. Mac に合う DMG をダウンロードします。Apple M1 以降は `arm64`、Intel Mac は `x86_64` を選択してください。
3. DMG を開き、**Menu Hub** を「アプリケーション」へドラッグします。
4. DMG を取り出し、「アプリケーション」または Spotlight から Menu Hub を起動します。
5. メニューバーの四つ葉アイコンを探します。Dock アイコンや通常のメインウインドウは表示されません。

同じリリースページに ZIP と SHA-256 チェックサムもあります。正式版は Developer ID で署名され、Apple の公証と Gatekeeper の検証を受けています。

## アクセシビリティ権限

アクセシビリティ権限により、対応するメニューバー項目を検出して通常のクリック操作を実行できます。権限がなくても制限付きのアプリランチャーモードは利用でき、画面収録権限は不要です。

1. **設定 > アクセシビリティとプライバシー** を開き、**システム設定を開く** をクリックします。
2. **プライバシーとセキュリティ > アクセシビリティ** で **Menu Hub** を有効にします。
3. 一覧にない場合は `+` から `/Applications/Menu Hub.app` を追加します。
4. Menu Hub に戻ると、権限を再確認して再スキャンします。

有効にしても認識されない場合は、Menu Hub の同じ設定画面で **権限を修復** を実行し、システム設定で再度有効にしてから **再スキャン** してください。この操作がリセットするのは Menu Hub の `com.local.MenuHub` エントリだけです。

## 使い方

アクセシビリティ権限が有効な場合、Menu Hub はメニューバーアイコンの横に未読合計をモノクロで表示します。macOS が公開する正確な数字だけを集計し、数字のない点は 0 として扱います。**設定 > 項目とグループ** で各項目を「自動／常に含める／含めない」に変更できます。

- 四つ葉アイコンをクリックしてパネルを開閉します。Option キーを押しながらクリックすると管理領域を隠す／表示できます。
- どのアプリからでも `⌥M` でパネルを切り替えられます。**設定 > ショートカット** で変更できます。
- アプリ名または項目名で検索し、項目をクリックして元のメニューバー操作を実行します。
- `↑` / `↓` で選択、`Return` で実行、`⌘Return` でホストアプリを開き、`⌘K` でアクションを表示、`Esc` で検索の消去またはパネルを閉じます。
- お気に入り、最近使用、頻繁に使用、カスタムグループ、別名、順序、除外項目は **設定 > 項目とグループ** で管理できます。

## 言語、プライバシー、制限

Menu Hub は 10 言語に対応します。**設定 > 一般 > 言語** で macOS に合わせるか、言語を選択できます。未対応のシステム言語では英語にフォールバックします。

カタログ、設定、使用履歴は `~/Library/Application Support/Menu Hub/` にのみ保存され、分析データやユーザーデータを送信しません。

macOS の公開 API では、すべての他社製メニューバー項目を確実に管理できません。時計やコントロールセンターなどのシステム項目は非表示の保証対象外です。安定したアクセシビリティ情報や `AXPress` がない項目はホストアプリを開くだけの場合があります。互換性は macOS、ディスプレイ構成、他社アプリのバージョンにも左右されます。
