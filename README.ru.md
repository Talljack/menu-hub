Menu Hub — нативный менеджер строки меню macOS. Нажмите значок с четырьмя лепестками, чтобы искать, распознавать, упорядочивать и активировать элементы строки меню запущенных приложений.

Приложение создано с помощью Swift 6, SwiftUI и AppKit и использует только публичные API macOS. В нём нет Electron, внедрения кода, разрешения на запись экрана, аналитических SDK, облачных сервисов и учётных записей.

## Установка

1. Откройте [последний выпуск на GitHub](https://github.com/Talljack/menu-hub/releases/latest).
2. Скачайте подходящий DMG: `arm64` для Apple M1 и новее, `x86_64` для Mac с Intel.
3. Откройте DMG и перетащите **Menu Hub** в папку **Программы**.
4. Извлеките DMG и запустите Menu Hub из папки «Программы» или через Spotlight.
5. Найдите значок с четырьмя лепестками в строке меню. Menu Hub не показывает значок в Dock и обычное главное окно.

На той же странице доступны ZIP-архивы и контрольные суммы SHA-256. Официальные версии подписаны Developer ID, нотариально заверены Apple и проверяются Gatekeeper.

## Разрешение Универсального доступа

Разрешение Универсального доступа позволяет находить поддерживаемые элементы и выполнять их обычное нажатие. Без него Menu Hub остаётся доступен в ограниченном режиме запуска приложений. Разрешение на запись экрана не требуется.

1. Откройте **Настройки > Разрешения и конфиденциальность** и нажмите **Открыть Системные настройки**.
2. Включите **Menu Hub** в разделе **Конфиденциальность и безопасность > Универсальный доступ**.
3. Если Menu Hub отсутствует, нажмите `+` и выберите `/Applications/Menu Hub.app`.
4. Вернитесь в Menu Hub: приложение повторно проверит разрешение и выполнит сканирование.

Если переключатель уже включён, но доступа всё ещё нет, выберите **Восстановить разрешение**, снова включите Menu Hub в Системных настройках и нажмите **Повторное сканирование**. Сбрасывается только запись `com.local.MenuHub` для Menu Hub.

## Использование

При разрешённом Универсальном доступе Menu Hub показывает рядом со значком монохромный счётчик всех непрочитанных сообщений. Учитываются только точные числа, доступные через macOS; точка без числа считается нулём. В **Настройки > Элементы и группы** для каждого элемента можно выбрать Автоматически, Всегда учитывать или Не учитывать.

- Нажмите значок с четырьмя лепестками, чтобы открыть или закрыть панель. Нажмите его с Option, чтобы скрыть или показать управляемую область.
- Используйте `⌥M` в любом приложении. Сочетание можно изменить в **Настройки > Сочетания клавиш**.
- Найдите приложение или элемент и нажмите результат, чтобы выполнить обычное действие.
- `↑` / `↓` выбирают элемент, `Return` запускает действие, `⌘Return` открывает приложение, `⌘K` показывает действия, а `Esc` очищает поиск или закрывает панель.
- Избранное, недавние и часто используемые элементы, группы, псевдонимы, порядок и исключения настраиваются в **Настройки > Элементы и группы**.

## Язык, конфиденциальность и ограничения

Menu Hub поддерживает 10 языков. В **Настройки > Основные > Язык** можно следовать настройкам macOS или выбрать язык. Для неподдерживаемого системного языка используется английский.

Каталог, настройки и история хранятся только в `~/Library/Application Support/Menu Hub/`. Menu Hub не отправляет аналитику или пользовательские данные.

Публичные API macOS не гарантируют управление всеми сторонними элементами строки меню. Системные элементы, включая часы и Пункт управления, не входят в гарантию скрытия. Элементы без стабильных данных Универсального доступа или `AXPress` могут только открывать своё приложение. Совместимость также зависит от macOS, конфигурации дисплеев и версий сторонних приложений.

Сведения о сборке, CI и технической документации находятся в [README на английском](README.md).
